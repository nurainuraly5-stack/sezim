# Sezim — Days you can feel again

Sezim собирает день из **текста, фото и песни** в живую сферу воспоминания и сцену дня.
Цвет, одна из пяти художественных техник, ритм кадров и дыхание сферы выводятся из ввода по явным правилам, без словаря «эмоция = цвет».
Текст читает модель (Anthropic) или, без ключа, упрощённый анализ — каждый день честно помечен, чем он посчитан.
Панель «Почему так выглядит» объясняет решения цифрами, а «Сравнить с другим текстом / песней» показывает, что меняет каждый вход.
Всё хранится только в браузере посетителя (IndexedDB); день выгружается папкой `.zip`.

**Production: https://sezim-iota.vercel.app** — без входа; при первом открытии архив сам собирает демо-дневник из 6 дней (~10 с).

## Запуск (3 команды)

```bash
git clone https://github.com/nurainuraly5-stack/sezim.git && cd sezim
npm install
npm run dev        # http://localhost:3000
```

Ключи не нужны: без них работает упрощённый анализ текста и голос браузера. Проверено на чистой папке (Node.js 26, npm 11):
`npm install` — около 2 минут, зависит от сети; сервер отвечает через ~6 с, демо-дневник из 6 дней собирается за ~5 с.
Production-сборка: `npm run build && npm start`. Тесты `npm run test:*` используют встроенный в Node запуск TypeScript (Node ≥ 23).

## Анализ текста моделью: `ANTHROPIC_API_KEY`

Создайте `.env.local` (образец — `.env.example`) или задайте переменные в Vercel → Settings → Environment Variables:

```bash
LLM_PROVIDER=anthropic          # без этой строки ключ не используется
ANTHROPIC_API_KEY=sk-ant-...    # ключ Anthropic
LLM_MODEL=claude-sonnet-5-5     # необязательно; по умолчанию claude-opus-5-5 (на production — claude-sonnet-5-5)
```

**Без ключа (или при `LLM_PROVIDER=none`, ошибке API, таймауте модели 9 с) работает упрощённый режим:** анализ текста по русским
маркерам прямо в браузере. Приложение полностью рабочее, день помечается «упрощённый анализ», название собирается из слов самого
текста. Режим можно включить и вручную: `/?llm=off` (значок «LLM выключен», кнопка «Включить» возвращает модель).

Облачная озвучка (`TTS_PROVIDER`, `OPENAI_API_KEY`, `ELEVENLABS_*`) есть в коде, но не проверена и в демо не используется —
голос даёт синтез речи браузера.

## Как проверить за 3 минуты

1. **Архив** (`/`): 6 разных сфер. «Сферы / Лента» — в ленте дни идут подряд (один автор, один каркас, разные сферы и техники).
2. **День** («Открыть день»): сцена фото в технике дня, живая сфера, «Слушать день», «Почему так выглядит», «Атмосфера дня», «Экспорт папки .zip».
3. **A/B по тексту**: на дне 16 ноября (шоколадный рулет) — «Сравнить с другим текстом» в карточке текста; вставьте текст дня
   19 ноября (концерт). Те же фото и песня: Soft Strokes → Geometric Tension, энергия около 28% → 76%, день → ночь, темп 95 → 126 BPM (числа зависят от ответа модели);
   «Что изменил текст» перечисляет пришедшие и ушедшие детали. «Заменить» делает новый текст текстом дня.
4. **A/B по песне**: «Сравнить с другой песней» — другой день, свой файл (анализ звука) или ссылка (оценка по метаданным).
5. **Новый день** (`/new`): текст → фото → песня. Живое превью меняется на каждом шаге, «Создать воспоминание» сохраняет день.
6. **Телефон**: всё то же на 390 px.

## Как это устроено

```
ввод ─┬─ текст ──► /api/analyze (LLM → JSON, zod, таймаут 9 с, кэш по хэшу ввода)
      │            └─ нет ключа / ошибка / таймаут / ?llm=off → упрощённый анализ, пометка в дне
      ├─ фото ───► k-means палитра, яркость, контраст, насыщенность, температура, яркий акцент
      └─ песня ──► файл: FFT → темп, энергия, яркость, лад (с уверенностью; неуверенный — «≈»)
                   ссылка: встроенный плеер + oEmbed → ОЦЕНКА по метаданным (подписана честно)
                         ▼
                  MoodProfile — непрерывный вектор (core/mood.ts)
                         ▼
                  Style Engine — чистые детерминированные функции (core/style-engine.ts)
                         ▼
             StyleTokens + explain[] ──► WebGL (свой GLSL: сцена + сфера) + Web Audio ──► IndexedDB (Dexie)
```

- **Техника — по баллу соответствия.** У каждой из 5 техник профиль: к какому значению тянется каждый признак и насколько он
  важен (энергия, светлость, тепло, плотность событий, объём текста, противоречие, ночь в тексте, темнота и число фото).
  Балл 0..1 — взвешенная близость дня к профилю; побеждает наибольший, в «Почему» — 2–3 главные причины и второе место.

  | Техника | Референс | Тянется к |
  |---|---|---|
  | Soft Strokes | импрессионизм: мазки и мягкий свет | светлый, спокойный, тёплый день |
  | Geometric Tension | Кандинский: линии, пятна, жёсткая сетка | энергия, плотность событий, противоречие |
  | Film Grain Night | плёночная фотография: зерно, виньетка, ореолы | ночь, тёмные снимки, приглушённая энергия |
  | Ma / Quiet Minimal | японское «ма»: пустота как содержание | мало слов и событий, тишина |
  | Collage | коллаж: много кадров, плотная память | много событий, длинная запись, много фото |
- **Палитра** — из фото; текст сдвигает её к своей температуре, лад — к тёплой или холодной доле, энергия — насыщенность.
  Без фото — непрерывная ось температуры текста (холод → сирень → тепло, в обход зелёного).
- **Смешанные состояния видны внутри сферы**: оболочка — «внешняя» температура (фото, холодные детали), ядро — «внутренняя».
- **Темп дня**: файл песни задаёт его сам; песня по ссылке подмешивается к темпу текста с весом доверия (16–40%).
  Темп → дыхание сферы (вдох на такт) и ритм смены кадров.
- **Сфера** уникальна для дня: сид из текста, палитры, признаков песни и времени создания (`core/orb.ts`).
- **Название** — 3–7 слов: с LLM его даёт модель, без LLM — только слова самого текста. Можно переименовать.
- Дни, посчитанные прошлой версией правил, пересчитываются из своих признаков при открытии (`STYLE_VERSION`).

| Папка | Что |
|---|---|
| `core/types.ts` | контракт: MoodProfile, StyleTokens, AudioFeatures, DayEntry |
| `core/analyze/` | анализ текста (упрощённый и слияние с LLM), фото, аудио, ссылок |
| `core/mood.ts`, `core/style-engine.ts` | признаки → настроение → стиль + объяснение |
| `core/orb.ts`, `core/ab.ts` | параметры сферы; версия дня с другой песней или другим текстом |
| `core/gl/` | GLSL-шейдеры сцены и сферы |
| `components/` | интерфейс: архив, день, сравнение, сфера, сцена, «Почему» |
| `lib/` | конвейер, IndexedDB, ZIP, плеер, демо-дневник (`seed.ts`) |
| `lib/server/llm.ts`, `app/api/` | `/api/analyze` (LLM + oEmbed), `/api/tts` |
| `scripts/` | тесты и фикстуры |

## Тесты

| Команда | Что проверяет |
|---|---|
| `npm run test:techniques` | крайние случаи выбора техники (короткий, длинный, громкая ночь, тихий день…), все 5 техник достижимы, формулировки «Почему» не противоречат числам, текст меняет токены при тех же фото и песне |
| `npm run table:techniques` | баллы 5 техник по демо-дням (`-- --fallback` — упрощённым анализом) |
| `npm run test:llm` | настоящий SDK против локального mock API: zod, таймаут 9 с, отказ/401/429/500 → упрощённый анализ |
| `npm run test:orbs` | сферы разных дней различимы, один день → те же параметры |
| `npm run test:audio` | темп и тональность на WAV с известными значениями и 192 синтетических треках |
| `npm run test:titles` | название без LLM: 3–7 слов и только слова текста |
| `npm run check:tokens` | контраст текста и фона по WCAG AA |

## Демо-дневник

6 дней одного автора — записи, фото и песни команды (`public/seed/seed-v2/day-N/`). Дни проходят обычный конвейер; название,
настроение, палитру и технику выдаёт система. Названия дней даёт модель, при новой сборке они могут отличаться. Песни — только ссылки YouTube, аудио в репозитории нет; фото уменьшены, без EXIF,
личные данные обрезаны (`docs/tools.md`). Пересобрать: `/?reseed=1`. Проверка на production — `docs/evaluation/rc/`; примеры дней (сцена, «Почему», сравнение, `/new`, телефон) — `docs/evaluation/final/`.

## Честность и ограничения

- Sezim не делает медицинских или психологических выводов: «Атмосфера дня» описывает день, а не человека. Голоса синтезированные.
- Песня по ссылке не анализируется как звук: темп и лад подписаны «оценка по метаданным» или «заданы вручную».
- Лад у поп-петель (мажор и параллельный минор) показывается как «≈»; темп иногда ошибается в октаву.
- Модель недетерминирована: названия демо-дней от сборки к сборке немного меняются.
- Проверено: Chrome, Edge, Chromium и WebKit (Playwright, Windows), 1366–2560 px и телефон 390 px. Не проверено на настоящих
  iPhone/Android и в Firefox.
