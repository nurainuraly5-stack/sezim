# Оценка жюри — Sezim (Genesis ArtTech «Make the Invisible Visible»)

_пт 20.11.2026. Оценщик: Claude, роли «строгий член жюри» и Lead Developer. Код не менялся, ждём подтверждения списка правок._

**Как проверял.** `npm run build`, затем `next start` (production). Прогон в Playwright: Chromium с реальным GPU (Intel UHD 620), 1440×900 и 390×844 с тачем, свежий профиль без данных. Сценарий: первое открытие → seed → лента → 6 дней со звуком → `/new` (текст + своё JPG-фото + свой WAV) → день → ZIP → ещё 2 дня (тот же трек + другой текст; тот же текст + другой трек) → A/B → поиск → флаг «LLM выключен» → телефон. Скриншоты лежат в `docs/evaluation/`, лог прогона — `docs/evaluation/run-log.txt`.

**Важно.** Оценено рабочее дерево с **незакоммиченными** правками этой сессии: исправление лада, цвет без зелёного, проверки LLM на mock-сервере, флаг «LLM выключен», тесты `test:audio` и `test:llm`. В `main` их пока нет. Публичного деплоя нет: ни ссылки в репо, ни упоминания в документах.

## 2. Итог

**61 / 100.**

Прогноз честно: в текущем виде **в топ-7 из 30 скорее не попадаем**. Без публичной ссылки и без 5 документов жюри срежет баллы ещё до просмотра. Сильная сторона — честный движок с объяснениями, A/B по песне и тесты. Это редкость, но её надо **показать**, а сейчас она спрятана в коде. Если закрыть P0 и пункты 1–6 из списка ниже, реально выйти на **75–80**: это уровень топ-7.

## 3. Обязательный минимум (P0)

| Пункт | Работает | Доказательство |
|---|---|---|
| Ввод: текст + ≥ 1 фото + песня (ссылка или файл) | **да** | `/new`: JPG + WAV → день за 0,24 с; при пустой форме три ошибки (`04-new-1440.png`, лог) |
| Вывод строится из ввода, не из шаблонов | **частично** | Палитра из фото (k-means), техника по баллам `scoreTechniques`, сфера по сиду ввода (`core/orb.ts`), 19 900 пар различимы (`test:orbs`). **Но** названия seed-дней заданы вручную (`lib/seed.ts:70`), а у пользовательских дней название — фрагмент текста: «Потом сидели на кухне» для дня похорон |
| Музыка заметно влияет и звучит | **частично** | Звучит: `currentTime` 3,0 с на всех 6 днях; файл анализируется (74 BPM, A minor). Влияет на ритм, вдох, зерно и температуру (A/B, `08-ab-compare.png`). **Но** на статичном кадре разница мала, а технику меняет только у 1 из 6 seed-дней |
| Название дня 3–7 слов | **частично** | В прогоне 3–6 слов. В коде не гарантировано: `core/analyze/text-fallback.ts:79` при коротком тексте отдаёт 1–2 слова |
| Отдельная папка дня | **да** | ZIP `2026-11-20_Потом-сидели-на-кухне/`: entry.json, photos/01.jpg, song.json, song.wav, memory.json, thumb.png |
| Архив с возвратом к любому дню | **да** | Сферы + лента + поиск; «Назад к архиву»; панель дня на ноутбуке, переход по касанию на телефоне |
| ≥ 3 разных настроения в единой системе | **да** | 5 классов в seed (`test:orbs` п. 4); визуально — `01-archive-1440.png`, `02-feed-1440.png` |
| Рабочая ссылка без логина | **нет** | Деплоя нет. Есть только приватный GitHub |
| Проверить по инструкции | **частично** | `npm install` → `cp .env.example .env.local` → `npm run dev` работает, но README описывает несуществующие части |
| Юридическое: данные свои/вымышленные | **да** | Seed-дневник вымышленный, фото — свои SVG (`public/seed/`) |
| Музыка: ссылки или свободная лицензия с атрибуцией | **да** | Процедурная, CC0, атрибуция «Sezim procedural (CC0)» в метаданных песни. В `tools.md` не описана, потому что файла нет |
| Голоса синтезированные | **да** | `speechSynthesis` (Microsoft Irina); OpenAI/ElevenLabs без ключа → 501 |
| Нет медицинской/психологической диагностики | **да** | Промпт LLM: «Never diagnose» (`lib/server/llm.ts`); в интерфейсе: «не оценка состояния человека» |

- Деплой и поведение на Vercel: деплоя нет.

- Safari и iOS: прогон только в Chromium.

- Анализ аудио на живых записях с вокалом: тесты только на синтетике.
