Песни всех шести дней — ссылки с приблизительной оценкой, поэтому смена песни меняет ритм, дыхание и фактуру, но не технику. Сильнее музыка влияет при файле или при ручном темпе и ладе.

## Техника

- `npm run build`, `test:orbs`, `test:audio`, `test:llm`, `test:titles`, `check:tokens` — все проходят.
- Первый вход (демо-дневник из 6 дней): 3,1–5,7 с на 1440 px, 1,4–3,2 с на 390 px (тот же ПК, эмуляция телефона), прогресс виден.
- 390 px: горизонтальной прокрутки нет (архив и 6 экранов дня — 0 px).
- `?llm=off`: значок «LLM выключен», все дни «упрощённый анализ».
- Поиск: «снег» → 1, «17.11» → 1, «блинчики» → 1, «ноябр» → 6.
- Песня: встроенный плеер YouTube (`youtube-nocookie`) открывается только по нажатию.
- Ошибок консоли нет.

## Не проверено

- Safari / iOS: не проверялись. Звук стартует только по нажатию, это видно по коду и по Chromium.
- Живой LLM: на Vercel нет ключа, все дни собраны упрощённым анализом.
- Реальный анализ аудио для ссылок: его нет по устройству. Песни по ссылке — только оценка по метаданным.
- Телефон: только эмуляция 390 px в Chromium на ноутбуке, живые устройства не проверялись.
