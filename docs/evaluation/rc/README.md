## Устойчивость seed
- Старый флаг / флаг v2 / частичная база (с флагом и без) → 6 из 6 с первого захода, все от модели.
- Сбой загрузки одного файла демо-дня → повтор, 6 из 6 (до c38dc59 было 5 из 6 на первом заходе).
- К модели одновременно не больше 3 запросов; сборка ~10–11 с от открытия страницы.

## Что НЕ проверено
- Настоящий iPhone / Android и Safari на macOS (только эмуляция WebKit в Playwright на Windows).
- Firefox.
- Озвучка через серверный TTS (на production не настроен — голос браузера).
- Свой аудиофайл в сравнении на production (проверялся локально в прошлых итерациях).
- Нагрузка: много посетителей одновременно (лимиты Anthropic API на аккаунте).
- Длительная стабильность ответов модели: таблица снята в одной сборке; названия варьируются.
