# Пустой архив на десктопе — 21.11.2026

**Симптом**: на ПК на https://sezim-iota.vercel.app нет ни одной демо-сферы, на телефоне есть; Playwright показывал 6 из 6.

**Причина**: `seedIfEmpty` решал по флагу `sezim:seeded` в localStorage, а не по содержимому IndexedDB.
На профиле, где сайт уже открывали (старая версия ставила флаг `'1'`), флаг переживал очистку базы или прерванную
сборку демо-дней (вкладку закрыли раньше, чем дни записались) → код считал, что «демо удалены пользователем», ставил `'v2'`
и больше никогда не собирал дневник. Ошибок в консоли нет. Частичная база с флагом тоже не досоздавалась.
Тест не ловил: каждый прогон — свежий профиль без флага.

**Исправление** (`lib/seed.ts`, `lib/db.ts`): у демо-дней постоянные id `seed-v2-day-N`; при каждом открытии архива
недостающие дни досоздаются; удалённые вручную запоминаются в IndexedDB (`cache['seed:removed']`) и не возвращаются;
старый флаг удаляется. Без WebGL — плоские сферы и сообщение в архиве.

## Сценарии хранилища (Chrome, 1366×768; сферы на первом заходе / после перезагрузки)
| Сценарий | До | После |
|---|---|---|
| старый флаг `'1'` + пустая база | 0 / 0 | 6 / 6 |
| флаг `'v2'` + пустая база | 0 / 0 | 6 / 6 |
| 2 дня из 6, флаг `'v2'` | 2 / 2 | 6 / 6 |
| 2 дня из 6, без флага | 6 / 6 | 6 / 6 |
| пустая база без флага | 6 / 6 | 6 / 6 |
| удалить демо-день через интерфейс | — | 5 / 5 (не возвращается) |

## Матрица браузеров (свежий профиль, production до исправления)
Chrome / Edge / Chromium в окне, headless с GPU, по умолчанию (SwiftShader), `--disable-gpu`, `--disable-webgl`, WebKit ×
1366×768@1, @1.25, 1920×1080@1, @1.5, @2, 2560×1440@1: **54/54 — 6 сфер**, canvas ненулевой, горизонтальной прокрутки нет.
Без WebGL — 6 плоских CSS-сфер (после исправления — с сообщением). В консоли только шум: предупреждение
SwiftShader «GPU stall due to ReadPixels», отменённые blob:-запросы миниатюр при пересборке списка.
