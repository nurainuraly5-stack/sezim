## Сделано (v0.1)
- Скелет Next.js 15 (App Router) + TS + Tailwind 4; зависимости: `dexie`, `zod`, `motion`, `jszip`, `@anthropic-ai/sdk`, `server-only`.
- **core/**: контракт типов; анализ текста (fallback без LLM), фото (k-means), аудио (FFT → BPM, энергия, centroid, лад с весом тоники в басу), ссылок (embed + оценка по метаданным); `mood.ts`; `style-engine.ts` (5 техник с явными условиями, сфера оболочка/ядро, explain[]); GLSL сферы и сцены.
- **API**: `/api/analyze` (Anthropic + zod, таймаут 8 с, oEmbed), `/api/tts` (openai | elevenlabs; 501 → speechSynthesis).
- **UI**: архив (поле сфер + лента + поиск), `/new` (живое превью), `/day/[id]` (WebGL-сцена, вход со звуком, озвучка с приглушением музыки, «Почему», переименование, экспорт ZIP, удаление). Адаптив: телефон 390px и ноутбук 1440px.
- **Seed**: 6 дней, SVG-заглушки, процедурная музыка CC0 → реальный аудио-анализ; авторские названия; сферы появляются по одной.
- **Устойчивость**: обработка потери WebGL-контекста; запасной вид дня без WebGL; ошибки шейдера не роняют страницу.
- **Проверено в браузере** (Playwright + реальный GPU Intel UHD 620, production-сборка):
  - seed 6 дней ≈ 6–9 с; создание дня ≈ 0,3–1 с; ошибок консоли нет (кроме ожидаемого 501 TTS без ключа);
  - все 5 техник в seed; BPM верен 6/6; лад верен 5/6;
  - поиск «снег» → 1 из 6; ссылка YouTube → oEmbed-название и embed-плеер, который играет после входа.

  - (в) Исправления по проверкам (все правила общие, проверены на 300 случайных днях, не подогнаны под seed):
    - «Почему»: причина техники выводится, только если признак действительно к ней тянет (было «спокойный день (возбуждение 60%)», «плотный текст (30%)»); если ни один признак не выражен — так и написано.
    - Film Grain Night: «ночь» только из текста (тёмные фото уже учтены отдельно — раньше темнота считалась дважды, и шумный ночной концерт уходил в плёнку); тяжесть дня (низкая светлость) весит больше; Soft Strokes штрафуется при светлости < 40% (мягкий свет — не про тяжёлый день). Seed: 3 техники (Geometric, Film Grain Night ×2, Soft Strokes ×3).
    - Песня по ссылке: оценка по метаданным учитывается с весом пропорционально её уверенности (жанр не распознан → 16%, а не 40%); энергия для зерна/резкости — смесь возбуждения дня и оценки по тому же весу. Строка «Почему» говорит «приблизительная оценка по метаданным … учтена с весом N%».
    - Текст влияет на палитру при том же фото: если тепло дня отличается от тепла снимков больше чем на 5,5%, палитра сдвигается к температуре текста (как лад песни); написано в «Почему».
    - Фото: акцентный цвет (`accent`, + к контракту) — яркие пиксели меньшинства (салют, свет), если их нет среди пяти главных; заменяет самый избыточный цвет палитры. У энергичного дня (возбуждение ≥ 60%) ядро сферы — этот акцент (иначе концерт и тяжёлый день с одинаковым теплом давали одинаково сиреневые сферы).

## Известные баги / риски
- Анализ аудио проверен только на синтетике; поп-петли почти всегда «≈» (честно, но часто). Ошибки темпа в октаву (172 → 86) остаются.
- Два seed-дня («Сдала за пять минут», «Мокрый асфальт») показывают «≈ минор»: браузерный синтез seed даёт уверенность 0,34/0,39.
- Тот же трек + другой текст при том же фото почти не меняет результат (палитра и техника от фото) — в работе.
- «Почему»: подписи шкал словами расходятся с числом («спокойный день (возбуждение 60%)», «светлое настроение (39%)»).
- Не проверено: синтез через OpenAI/ElevenLabs (нет ключа) — изменены только параметры запроса; LLM-анализ вживую (нет ключа).
- Голоса Google/Edge Natural проверены только логикой выбора (в Playwright-Chromium их нет); вживую — только Microsoft Irina/Pavel.
- A/B в seed-дневнике (проверено перебором всех 30 пар в браузере): техника меняется только у «Сдала за пять минут до конца» — с любой песней другого дня Geometric Tension → Soft Strokes; **это день для демо A/B**. У остальных пяти дней техника держится (её задают текст и фото), музыка меняет ритм, вдох, зерно/резкость и тепло.
- A/B для дня с LLM-анализом без сети и без кэша: версия A пересчитывается упрощённым анализом текста и может отличаться от сохранённой — показывается пометка.
- Без расширения KHR_parallel_shader_compile (часть мобильных браузеров) компиляция синхронная — прогрев в архиве тогда сам даёт паузу, но в архиве, а не при открытии дня.
- Проверка в Playwright: поле даты показывается в формате локали браузера (там en-US); у пользователей с русской локалью — дд.мм.гггг.
- В dev-режиме первый переход на `/day/[id]` медленный (компиляция по требованию) — в production нет.
- Fallback-время суток считает по числу упоминаний («утром… вечером» → утро).
- Кувахара в Soft Strokes тяжёлая на слабых GPU — DPR сцены ограничен 1.5.
