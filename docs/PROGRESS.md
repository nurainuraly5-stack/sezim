# PROGRESS — Sezim

_Обновлено: чт 19.11.2026 — тег `v0.1` на `0fcdedd`; начат v0.2_

## Сделано (v0.1)
- Скелет Next.js 15 (App Router) + TS + Tailwind 4; зависимости: `dexie`, `zod`, `motion`, `jszip`, `@anthropic-ai/sdk`, `server-only`.
- **core/**: контракт типов; анализ текста (fallback без LLM), фото (k-means), аудио (FFT → BPM, энергия, centroid, лад с весом тоники в басу), ссылок (embed + оценка по метаданным); `mood.ts`; `style-engine.ts` (5 техник с явными условиями, сфера оболочка/ядро, explain[]); GLSL сферы и сцены.
- **API**: `/api/analyze` (Anthropic + zod, таймаут 8 с, oEmbed), `/api/tts` (openai | elevenlabs; 501 → speechSynthesis).
- **UI**: архив (поле сфер + лента + поиск), `/new` (живое превью), `/day/[id]` (WebGL-сцена, вход со звуком, озвучка с приглушением музыки, «Почему», переименование, экспорт ZIP, удаление). Адаптив: телефон 390px и ноутбук 1440px.
- **Seed**: 6 дней, SVG-заглушки, процедурная музыка CC0 → реальный аудио-анализ; авторские названия; сферы появляются по одной.
- **Устойчивость**: обработка потери WebGL-контекста; запасной вид дня без WebGL; ошибки шейдера не роняют страницу.
- **Проверено в браузере** (Playwright + реальный GPU Intel UHD 620, production-сборка):
  - seed 6 дней ≈ 6–9 с; создание дня ≈ 0,3–1 с; ошибок консоли нет (кроме ожидаемого 501 TTS без ключа);
  - все 5 техник в seed; BPM верен 6/6; лад верен 5/6;
  - поиск «снег» → 1 из 6; ссылка YouTube → oEmbed-название и embed-плеер, который играет после входа.

## Известные баги / риски
- Лад: «Пирог, лес и все свои» (G major) определяется как G minor; тоника иногда смещается на доминанту.
- В dev-режиме первый переход на `/day/[id]` медленный (компиляция по требованию) — в production нет.
- Fallback-время суток считает по числу упоминаний («утром… вечером» → утро).
- Кувахара в Soft Strokes тяжёлая на слабых GPU — DPR сцены ограничен 1.5.
- Не проверены: экспорт ZIP (кнопка есть, нажатие в автотесте не прогонялось), загрузка аудиофайла пользователем.
