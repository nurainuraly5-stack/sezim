# PROGRESS — Sezim

_Обновлено: чт 19.11.2026, вечер_

## Сделано
- Скелет Next.js 15 (App Router) + TS + Tailwind 4; зависимости: `dexie`, `zod`, `motion`, `jszip`, `@anthropic-ai/sdk`, `server-only`.
- **core/**: контракт типов; анализ текста (fallback без LLM), фото (k-means), аудио (FFT → BPM, энергия, centroid, лад), ссылок (embed + оценка по метаданным); `mood.ts`; `style-engine.ts` (5 техник с явными условиями, сфера оболочка/ядро, explain[]); GLSL сферы и сцены.
- **API**: `/api/analyze` (Anthropic + zod, таймаут 8 с, oEmbed), `/api/tts` (openai | elevenlabs; 501 → speechSynthesis).
- **UI**: архив (поле сфер + лента + поиск по названию и дате), `/new` (живое превью сферы, фото drag&drop, файл/ссылка песни, чипы темп/лад), `/day/[id]` (WebGL-сцена, вход со звуком, озвучка с приглушением музыки, «Почему», переименование, экспорт ZIP, удаление).
- **Seed**: 6 дней, процедурные SVG-фото, процедурная музыка CC0 → реальный аудио-анализ; авторские названия.
- Проверка движка на seed-текстах: используются все 5 техник; A/B (тот же текст, другая песня) меняет технику, палитру, ритм и зерно.
- `npm run build` проходит. README (запуск в 3 команды, схема).

## Известные баги / риски
- В браузере ещё не проверено (WebGL, seed-анализ, экспорт).
- Fallback-время суток считает по числу упоминаний («утром… вечером» → утро) — возможно, стоит брать последнее упоминание.
- Кувахара в Soft Strokes тяжёлая на слабых GPU — DPR сцены ограничен 1.5.
