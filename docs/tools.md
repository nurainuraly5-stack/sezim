# Инструменты и материалы

> Основной текст этого документа пишет команда. Ниже — материалы демо-дневника (seed v2), собранные по коду.

## Демо-дневник (seed v2)

Шесть дней одного автора лежат в `public/seed/seed-v2/day-N/`: текст, фото, ссылка на песню, дата. Название, настроение, палитру и технику каждого дня выдаёт прототип, вручную они не задавались. Рабочее название автора (`meta.json → userTitleHint`) хранится только для справки.

### Фото

Фото авторские, команды; предоставлены добровольно. Перед публикацией в репозиторий:

- все кадры уменьшены до ≤ 1280 px, метаданные (EXIF) удалены;
- день 2, фото 2: кадр обрезан до мониторов. Бланки с рукописными ФИО и рука человека не попали в кадр;
- день 4, фото 1: обрезана чёрная полоса сверху (дефект кадра);
- день 5: обрезан до стола с едой, люди за столом не попали в кадр;
- день 6, фото 1: обрезана подпись Instagram-истории поверх картины.

Оригиналы хранятся у команды локально, в репозиторий не попадают.

## AI-инструменты

| Инструмент | Где | Для чего |
|---|---|---|
| Claude Code | разработка | код, тесты, проверка production, отчёты |
| Claude в чате | подготовка | планирование, промпты, тексты документов |
| Модель Claude через API (`@anthropic-ai/sdk`, `/api/analyze`) | в приложении | анализ текста дня и название дня; без ключа — упрощённый анализ в браузере |

Картинки нейросетью не генерируются: сцена и сфера рисуются собственными шейдерами WebGL по параметрам из правил
(`core/style-engine.ts`, `core/gl/`), фото — авторские, команды.
