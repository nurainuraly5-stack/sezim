## 1. Продукт
- **Sezim** — название продукта. Слоган по умолчанию: *Days you can feel again.* («Дни, которые можно почувствовать снова»). Название используй везде (title, metadata, README, landing, UI), но в интерфейсе редко: одно небольшое лого в шапке, мягкие интеграции (подпись папки дня, водяной знак экспорта). **Memory Orbs** — это название механики (шары воспоминаний), а не продукта.
- **Механика:** каждый день = светящаяся сфера (Memory Orb) в архиве. На сфере/рядом — название дня и дата. Архив — пространство сфер: листать, искать по названию и по дате, открыть сферу → полноэкранное воспоминание дня (интерактивная сцена со звуком, подписью от руки, фото с обработкой, при наличии — озвучка).
- **Формат результата (по умолчанию, команда может изменить):** интерактивная веб-сцена воспоминания, рендерится в реальном времени (Canvas/WebGL + Web Audio). Экспорт в видео — P2.
- **Визуальная идентичность:** свет, память, чувства, светящиеся сферы; тёмная глубокая среда и много воздуха; свечение с фактурой (зерно/плёнка), объём, тонкая подсветка по краю. Без шаблонного glassmorphism и без стандартного вида shadcn/Tailwind. Не копируй внешний вид и цветовые коды чужих произведений (фильмов, игр, конкретных современных авторов): вдохновляйся техниками и направлениями.
- **Цвет сферы не берётся из словаря «эмоция = цвет».** Он считается из реальной палитры фото, темпа/лада песни и признаков текста. Смешанные состояния («холодно, но тёплое какао») видны внутри одной сферы: например, холодная оболочка и тёплое ядро.

## 2. Стек (зафиксирован)
Next.js (App Router) + TypeScript + Tailwind · IndexedDB через Dexie (без сервера, без авторизации) · 2 серверных роута: `/api/analyze` (LLM → JSON, валидация zod, таймаут 8 с) и `/api/tts` · WebGL-шейдер (свой GLSL) для обработки фото и сфер · Web Audio API · `motion` для UI-анимаций · деплой на Vercel. Провайдер LLM и TTS — за абстракцией, выбираются через env (`LLM_PROVIDER`, `TTS_PROVIDER`, ключи только на сервере, `.env.example` в репо). Пакеты ставь только по необходимости и объясняй зачем. Диффузионную генерацию изображений НЕ использовать.

## 3. Архитектура и контракт
Поток: ввод → признаки (LLM по тексту, анализ фото, аудио) → `MoodProfile` (непрерывный вектор) → `Style Engine` (чистые детерминированные функции) → `StyleTokens` + `explain[]` → рендер → сохранение.

Создай `core/types.ts` первым и не меняй без причины:
```ts
type MoodProfile = {
  valence: number; arousal: number; warmth: number; density: number; // 0..1
  tempo: number;            // BPM, оценка
  mode: 'major'|'minor'|'mixed'|'unknown';
  daypart: 'dawn'|'day'|'dusk'|'night'|'unknown';
  contrast: number;         // внутреннее противоречие: холодно но тепло
  motifs: string[];         // сенсорные детали из текста (3–6)
  quote: string;            // короткая фраза из текста для подписи
  title: string;            // 3–7 слов, единый тон
  voiceStyle: { pace: 'slow'|'mid'|'fast'; warmth: number };
}
type StyleTokens = {
  palette: string[]; technique: TechniqueId; grain: number; brush: number;
  duotone: number; sharpness: number; rhythm: number; // сек между кадрами
  typeWeight: number; motion: { speed: number; easing: string };
  orb: { core: string; rim: string; glow: number; breath: number };
}
type DayEntry = { id: string; date: string; text: string; photos: Blob[];
  song: { kind:'file'|'link'; url?: string; meta?: {title?:string; artist?:string; year?:number; genre?:string}; analysis?: AudioFeatures };
  mood: MoodProfile; tokens: StyleTokens; explain: string[]; voice?: Blob; createdAt: number }
```

## 4. Правила стиль-движка (реализовать явно)
Постоянное (в одном `Frame`): сетка, шрифтовой дуэт, место даты и подписи, способ встраивания фото, форма и подпись сферы. Переменное: палитра, обработка фото, фактура, композиция, ритм, анимация.
Библиотека техник (4–5, каждая — шейдер/параметры + условие включения + текстовое обоснование в `explain[]`):
- **Soft Strokes** (импрессионисты, мазки и мягкий свет) — спокойные, тёплые дни, низкая arousal, высокая valence.
- **Geometric Tension** (Кандинский: линии, пятна, жёсткая сетка) — высокая arousal, плотный/деловой текст, резкий ритм.
- **Film Grain Night** (плёночная фотография) — ночь/вечер, зерно, виньетка, тёмные тона.
- **Ma / Quiet Minimal** (японский минимализм) — тихие дни, мало слов, много пустоты.
- **Collage** — много фото/событий, высокая density.
Музыка влияет так: темп → скорость переходов и «дыхание» сферы; энергия → контраст, зерно, резкость; лад → тёплая/холодная доля палитры и плотность; жанр/эпоха → фактура. Если реального аудио нет (ссылка) — оценка по метаданным песни + редактируемые чипы «темп/лад»; **не выдавай это за анализ аудио**, подписывай честно.
`explain[]` — 3–5 коротких строк «Почему так выглядит» (показываются в панели «Почему»).

## 5. Входы
- **Текст:** `/api/analyze` возвращает MoodProfile-часть (valence, warmth, density, daypart, contrast, motifs, quote, title, voiceStyle). Fallback-движок без LLM (русскоязычные маркеры + эвристики) обязателен: если API упал, всё работает и помечается «упрощённый анализ». Кэш результатов по хэшу ввода.
- **Фото:** ресайз ≤1600px, палитра (свой k-means/median cut), яркость/контраст/насыщенность, число кадров.
- **Песня:** файл → реальный анализ в браузере (BPM, энергия, spectral centroid, мажор/минор по хроме; Essentia.js или Meyda, тайм-бокс 2 ч, иначе упрощённо); ссылка → embed-плеер (YouTube/Spotify iframe) + oEmbed-метаданные. Не используй Spotify audio-features (закрыто для новых приложений). Превью-API (iTunes/Deezer) — только после отдельного спайка, это P2.
- **Название дня:** 3–7 слов, единый тон и длина, по смыслу записи, редактируется пользователем.
- **Озвучка:** предрендер через TTS при создании, mp3 сохраняется в папку дня; fallback — `speechSynthesis` с rate/pitch по `voiceStyle`. Голоса только синтезированные.

## 6. Хранение и архив
День = «папка»: `entry.json`, `photos/`, `song.json` или аудио, `memory.json` (токены + explain), `voice.mp3`, `thumb.jpg`. В IndexedDB — единый объект дня; кнопка **«Экспорт папки .zip»** формирует реальную структуру папки. Архив: пространство сфер + лента 5–7 дней для ленточного теста, поиск по названию и дате, открыть/удалить день. Seed-дневник (6 вымышленных дней, 4–5 разных настроений, свободная музыка CC с атрибуцией) автозагружается при пустой базе; фото-заглушки в `public/seed/` заменим на команды-свои. Реальный пользовательский сценарий создания дня должен работать наравне с seed.

## 7. UX
Один экран записи: текст → перетащить фото → вставить ссылку/файл песни. **Живое превью:** сфера и палитра меняются, когда вставили фото или песню (причинность видна сразу). Создание дня ≤ ~10 секунд с красивым «процессом создания» (анимация сферы, а не спиннер). Панель «Почему так выглядит». Адаптивность (телефон и ноутбук). Старт звука только по клику (iOS/Safari). Ни одной неработающей кнопки, ни одного фейкового эффекта.
